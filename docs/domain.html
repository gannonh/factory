Levels

Issue lifecycle Linear
The issue's path through the team's Linear states. One per issue.
Round built for one stage
One entry of the issue into a stage's state. Not a turn, not an attempt. Rework is a new round on the same pull request (ADR 0012).
Flow built
One starting task plus every task its handoffs create. Exactly one per round.
Task built
One unit of work for one agent. Waits in the queue until a run starts.
Run built
One attempt at a task in a sandbox. A retry is another run.
Turn agent only
One exchange inside the agent process. Factory does not track it.
Human gate planned
A Linear state with no trigger. A person releases the issue by moving it.
