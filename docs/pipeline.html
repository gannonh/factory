An issue's lifecycle through the pipeline

Each Linear state either starts a stage (one round, which runs one flow of agents) or is a human gate where Factory waits for a person.

Key

Stage. A trigger on a Linear state. Each entry into the state starts one round, which runs one flow. Flow. The tasks a round runs: one on the stage's agent plus each task its handoffs create. Human gate. A state with no trigger. A person moves the issue on. Back edge. The issue stays or goes back. Re-entering a stage starts a new round.

Rules

  • Linear holds the issue's state. Factory reads it and never keeps a second copy.
  • Context between rounds lives on the issue and its PR: the workpad, Factory's notes and review threads.
  • A crashed round is replaced by a new round with the same inputs.
  • Moving an issue out of a stage's state cancels that stage's open round.
  • Every stage and gate can be turned off in the UI. The defaults run the full lifecycle.
